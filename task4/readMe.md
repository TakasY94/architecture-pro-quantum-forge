# README.md для Задания 4: Реализация RAG-бота с техниками промптинга

## Цель задания

Создать полностью работающего RAG-бота, который:
- выполняет семантический поиск по векторному индексу (из Задания 3),
- формирует ответы на основе найденных фрагментов,
- использует продвинутые техники промптинга: **Few-shot prompting** и **Chain-of-Thought (CoT)**,
- корректно обрабатывает случаи отсутствия релевантной информации («Я не знаю»).

Бот построен как отдельный проект, чтобы не зависеть от предыдущих шагов индексации.

## Выбранный стек

- **Векторная база**: ChromaDB (persistent, из Задания 3)
- **Модель эмбеддингов**: `BAAI/bge-m3` (та же, что при индексации)
- **LLM**: **GigaChat** через официальный API Сбера  
- **Техники промптинга**:
  - Few-shot: 2–3 примера ответов в промпте
  - Chain-of-Thought: явное указание модели сначала размышлять шаг за шагом


Установка:

```bash
pip install -r requirements.txt
```

## Запуск бота

```bash
python rag_bot.py
```

- Вопросы на русском языке.
- Для выхода: `exit`, `quit` или `выход`.

## Настройка параметров (config.py)

- `N_RESULTS = 5` — сколько чанков брать для контекста
- `RELEVANCE_THRESHOLD = 0.55` — порог cosine distance (подбери под свои данные: ниже — строже)
- `MAX_TOKENS = 800`, `TEMPERATURE = 0.7` — параметры генерации GigaChat
