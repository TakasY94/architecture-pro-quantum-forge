# Task 2: Обработка вики-страниц по вселенной Гарри Поттера

Этот проект включает загрузку, обработку и модификацию вики-страниц из вселенной Гарри Поттера. Основные задачи:
- Загрузка вики-страниц.
- Создание словаря соответствий терминов (старые -> новые).
- Замена терминов в текстах с учетом склонений.
- Переименование файлов в соответствии с новыми терминами.

## Зависимости

Установите необходимые библиотеки:

```bash
pip install pymorphy2
pip install requests
```

## Последовательность выполнения

### 1. Загрузка вики-страниц

Запустите скрипт для загрузки данных:

```bash
cd task2
python download.py
```

Это создаст папку `knowledge_base_raw/` с исходными файлами.

### 2. Проверка словаря терминов

Словарь терминов находится в `terms_map.json`. Он содержит соответствия старых терминов новым.

Пример:
```json
{
  "Гарри Поттер": "Гарольд Поттерман",
  "Альбус Дамблдор": "Альфред Дамблдон"
}
```

### 3. Замена терминов в текстах

Запустите скрипт для замены терминов с учетом склонений:

```bash
python replace_terms.py
```

Это обработает файлы из `knowledge_base_raw/` и создаст измененные файлы в `knowledge_base/`.

### 4. Переименование файлов

Запустите скрипт для переименования файлов в соответствии с новыми терминами:

```bash
python rename_files.py
```

Файлы в `knowledge_base/` будут переименованы.

## Структура проекта

- `download.py`: Загрузка вики-страниц.
- `terms_map.json`: Словарь соответствий терминов.
- `replace_terms.py`: Скрипт замены терминов с морфологическим анализом.
- `rename_files.py`: Скрипт переименования файлов.
- `knowledge_base_raw/`: Исходные файлы.
- `knowledge_base/`: Обработанные и переименованные файлы.
